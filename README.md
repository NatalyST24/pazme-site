PAZME — визуальное обновление действующего сайта (22.09.2026)

В этом пакете весь проект. Нынешние формы, выбор телефона или email, анкеты, согласие, аналитика, CSV и адрес наклейки остаются без изменений.

Изменения относительно уже загруженного PAZME_FINAL_WEBSITE:
• Реальный визуал первой страницы: фотография в городском стиле, утверждённый пазловый логотип, отдельный считываемый QR и те же согласованные тезисы.
• Фотография взята из согласованного визуала PAZME и подготовлена в размере для мобильного сайта.
• Доработаны отступы и типографика на телефонах; анкеты получают аккуратные общие стили.
• Установщик ждёт готовности Gunicorn до 20 секунд: ошибка «000» при мгновенном перезапуске больше не должна возникать.
• Ни один старый телефон/почта не удаляется; файл SQLite не должен попадать в GitHub.

Установка поверх уже работающего PAZME:
1. Зайдите в GitHub → NatalyST24/pazme-site → main. Ветка backup-before-forms сохранена.
2. Распакуйте ZIP. Загрузите СОДЕРЖИМОЕ папки PAZME_VISUAL_FIX_2026-09-22 в main через Add file → Upload files → Commit changes.
3. Selectel → PAZME → Console, по одной команде:
   cd /root/pazme-site
   git pull --ff-only
   bash deploy/update.sh
4. Дождитесь «PAZME updated...». Откройте https://pazme.ru/qr/ в приватной вкладке (или Ctrl+F5).
5. Если что-то не так, остановитесь и пришлите скрин. Не трогайте Wilma, DNS, certbot или базу.

Резервирование: update.sh перед обновлением копирует приложение и SQLite в /root/pazme-backups/.
Примечание: backup-before-forms в GitHub — старая версия ДО первого большого обновления, а непосредственно сегодняшняя версия дополнительно сохраняется в резервной копии на сервере при новом запуске update.sh.
Сайт не менялся напрямую в процессе подготовки архива; файлы сначала нужно загрузить в GitHub и на Selectel.
