# PAZME · размещение на Selectel

Готовая страница приглашений для `pazme.ru`. QR на утверждённой наклейке открывает `https://pazme.ru/qr/`. Сайт принимает заявки двух типов и ведёт агрегированный счёт открытий и ответов. Номера сохраняются в локальной SQLite-базе; SMS самостоятельно не отправляются.

## 1. Что нужно

- Зарегистрированный домен `pazme.ru` с доступом к DNS-записям.
- Новый облачный сервер Selectel с Ubuntu 24.04 LTS, публичным IPv4 и доступом по SSH.
- Входящие порты 80 и 443; SSH-порт 22 только с вашего IP, если возможно.
- Перед включением формы сбора номеров проверить необходимость и подать уведомление об обработке персональных данных в Роскомнадзор. Опубликованные согласие и политика включены в проект. Запланированное приглашение участникам не является согласием на дальнейшую рекламную рассылку.

## 2. Привязать домен к серверу

Найдите публичный IPv4 в панели Selectel. В действующих DNS-настройках домена создайте записи:

| Тип | Имя | Значение |
|---|---|---|
| A | @ | публичный IPv4 Selectel |
| A | www | тот же IPv4 |

Если у домена уже есть записи, сохраняйте MX и другие нужные записи. Переносить DNS в Selectel необязательно. Подождите обновления записей. Если `www` не настроен, при выпуске сертификата используйте только `pazme.ru`.

## 3. Установить сайт

Распакуйте архив. Папка проекта должна называться `PAZME`. В Windows откройте PowerShell в папке, содержащей `PAZME`, и выполните:

```powershell
scp -r .\PAZME LOGIN@SERVER_IP:~/
ssh LOGIN@SERVER_IP
```

Замените только `LOGIN` и `SERVER_IP` на логин SSH и публичный IP вашего сервера. Пароли и закрытые SSH-ключи никому не отправляйте.

В открывшейся консоли сервера:

```bash
cd ~/PAZME
sudo bash deploy/install.sh
```

Установка предназначена для нового сервера или сервера без сайта `pazme.ru`. Если установщик сообщил об уже существующей конфигурации `/etc/nginx/sites-available/pazme.ru`, остановитесь и проверьте старый сайт перед заменой.

## 4. Включить HTTPS

После того как обе DNS-записи указывают на сервер, запустите:

```bash
sudo certbot --nginx -d pazme.ru -d www.pazme.ru
```

Если `www.pazme.ru` отсутствует в DNS, используйте:

```bash
sudo certbot --nginx -d pazme.ru
```

Certbot попросит email для уведомлений о сертификате и согласие с условиями. Адрес для этих уведомлений можно указать свой.

## 5. Проверить страницу и запись заявки

Откройте в браузере:

`https://pazme.ru/qr/`

Убедитесь, что видите PAZME, выбираете «Да», роль, вводите свой номер и вручную ставите галочку. После отправки должна появиться благодарность. Проверьте также `https://pazme.ru/privacy/` и `https://pazme.ru/consent/`.

На сервере смотрите статистику:

```bash
sudo -u pazme env PAZME_DB=/var/lib/pazme/pazme.sqlite3 /opt/pazme/.venv/bin/python /opt/pazme/manage.py stats
```

`bag01` означает переходы по QR на вашей сумке. «Открытия» — зарегистрированные загрузки страницы браузером, а не точное число разных людей; «Да» и «Пока нет» — события выбора; «Отправки телефона» — успешные отправки, повторные отправки могут учитываться дважды. «Актуальные телефоны» уникальны по номеру.

## 6. Выгрузить контакты

На сервере в своём домашнем каталоге:

```bash
umask 077
sudo -u pazme env PAZME_DB=/var/lib/pazme/pazme.sqlite3 /opt/pazme/.venv/bin/python /opt/pazme/manage.py export > ~/pazme-leads.csv
```

В файле находятся телефон, роль (`participant` — участник, `business` — бизнес), источник, дата согласия и версия согласия. Передавайте файл только по защищённому каналу и не размещайте его в общедоступной папке сайта. Заявки не подтверждают владение указанным номером: проверяйте корректность контактов до дальнейшей работы.

## 7. Удаление по просьбе человека

Если человек отозвал согласие по email `n.law-2024@mail.ru`, удалите его контакт:

```bash
sudo -u pazme env PAZME_DB=/var/lib/pazme/pazme.sqlite3 /opt/pazme/.venv/bin/python /opt/pazme/manage.py delete '+79991234567'
```

Замените пример на номер из обращения. Ежедневный таймер автоматически удаляет контакты старше шести месяцев. После приглашения и завершения первого набора вручную удалите контакты, когда цель обработки достигнута. Удаляйте соответствующие копии из ранее сделанных выгрузок.

## 8. Обновить сайт после согласования нового текста

При обновлении проекта скопируйте новые файлы и согласуйте работу с текущим сайтом, прежде чем менять конфигурацию. Личная база лежит отдельно: `/var/lib/pazme/pazme.sqlite3`. Не переносите и не публикуйте этот файл. Серверный сервис перезапускается командой `sudo systemctl restart pazme`.

## Техническая структура

`index.html` — главная страница; `consent.html` и `privacy.html` — документы; `assets` — оформление; `app.py` — учёт посещений и сохранение контактов; `manage.py` — статистика, выгрузка и удаление; `deploy` — установка и конфигурация Nginx/systemd.

Статистика ведётся собственным счётчиком без Яндекс Метрики, внешних скриптов и аналитических cookie. Сервер Nginx настроен без журнала посещений; агрегированная статистика не содержит IP. Сама отправка номера происходит только после явного выбора роли и установки галочки согласия.
