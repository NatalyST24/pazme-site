PAZME — обновление действующего сайта

Этот комплект заменяет ВСЕ предыдущие архивы обновления. Используйте только PAZME_FINAL_WEBSITE.zip.
Работает на существующем сервере PAZME в Selectel. Wilma, DNS и HTTPS не меняет.

Что нового
• Утверждённая надпись PAZME со встроенными пазлами добавлена на главную, анкеты и юридические страницы.
• Первая страница объясняет PAZME конкретно и коротко: QR-наклейка, вознаграждение участнику за подтверждённый результат, новые клиенты для бизнеса.
• Роль и ответы «Да / Пока нет» остаются. После выбора роли можно оставить ИЛИ телефон, ИЛИ email.
• После отправки контакта открывается дополнительная анкета соответствующей роли: участник — имя и города; бизнес — имя, название, направление, города/онлайн, предложение первым клиентам и сайт/соцсеть.
• Согласие и политика охватывают оба способа связи и дополнительные поля. Убраны необязательные пояснения о рекламных рассылках.
• Администратор видит прежние и новые контакты; CSV содержит отдельные колонки «Телефон», «Электронная почта», «Способ связи», роль, географию и данные бизнеса. Email-адреса НЕ создаются автоматически, рассылка приглашений пока ручная.
• Адрес наклейки остаётся прежним: https://pazme.ru/qr/.

Шаг 1. GitHub — резервная копия
Вы уже создали ветку backup-before-forms из main. Она хранит исходный код до обновления.
Вернитесь в main. В backup-before-forms ничего не загружайте.

Шаг 2. Обновите main через браузер
Распакуйте архив. Откройте папку PAZME_ГОТОВО_ОБНОВЛЕНИЕ_КОНТАКТ.
GitHub → NatalyST24/pazme-site → main → Add file → Upload files.
Перенесите содержимое папки (включая app.py, index.html, participant.html, business.html, assets и deploy), не архив ZIP. Нажмите Commit changes.
На открытом GitHub не храните базу, выгрузки CSV и пароли.

Шаг 3. Обновите ТОЛЬКО сервер PAZME в Selectel
Selectel → VDS → PAZME → Консоль. Вводите по одной команде:

cd /root/pazme-site
git pull --ff-only
bash deploy/update.sh

Ждите «PAZME updated. Database and analytics preserved.»
НЕ запускайте deploy/install.sh и НЕ очищайте базу.
Обновляющий скрипт заранее сохраняет программу и согласованную копию SQLite в /root/pazme-backups/.

Шаг 4. Проверка
Откройте https://pazme.ru/qr/ на телефоне, обновите вкладку, проверьте новый заголовок.
Выберите «Да» → одну из ролей → телефон или почту → согласие → «Получить приглашение».
Далее заполните короткую анкету. Проверьте обе роли по очереди с ВАШИМИ тестовыми контактами.

Шаг 5. Аналитика и CSV
https://pazme.ru/admin/ (только HTTPS).
Логин: admin. Пароль хранится только на сервере PAZME:

cat /root/PAZME_ADMIN_PASSWORD.txt

Не присылайте скрин пароля и не загружайте его в GitHub. Скачанная CSV-выгрузка содержит персональные данные, храните её закрыто.

Если потребуется откат к предыдущему КОДУ сайта:

cd /root/pazme-site
bash deploy/rollback.sh

Код восстановится из резервной копии на сервере. Сохраняются обновлённая база и уже полученные заявки; резервная ветка GitHub остаётся.

Перед публичным сбором чужих контактов проверьте правовые формальности обработки персональных данных и уведомление Роскомнадзора. Приглашение по запросу и рекламная рассылка — разные цели обработки.

ВАЖНО: как работает загруженный QR
Адрес уже напечатанной наклейки не изменяется: https://pazme.ru/qr/.
Изображение QR внизу анкет сканируется и открывает главную страницу https://pazme.ru/.
Пазловое слово PAZME — визуальный логотип, само по себе QR-кодом не является.

ЧТО ИМЕННО ЗАГРУЖАТЬ В GITHUB
В архиве есть одна папка PAZME_FINAL_WEBSITE. Откройте её и загрузите СОДЕРЖИМОЕ в основную папку main.
